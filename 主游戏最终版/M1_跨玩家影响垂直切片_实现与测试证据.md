## 5. HIDDEN 安全边界

Viewer projection 的严格白名单不包含：

```text
sourceRoleId/sourceRoleKey/sourceRoleName/sourceActionId/playerActionId
 targetRoleId/targetRoleKey/dedupeKey/audience/rawAction/rawPayload
 suspectedRoleIds/canonicalPayload/privatePayload
```

除字段白名单外，递归扫描所有字符串，拒绝 `xunfu`、`巡抚`、`巡抚衙门`、`要求县令`、`只交副本`、`隐藏原粮册` 等来源语义别名。

公开质问响应固定为：

```text
preferredEntry = TALK
targetRoleKey = 不存在 / 前端传空字符串
prefill = 请相关经手方公开说明原始粮册为何未按登记送达。
```

因此打开人物交流工作区时不会预选、命名或暗示真实来源。

## 6. eventId 与幂等

- 内部幂等：`StoryEvent.dedupeKey = A_EMOTION_M1:<resolutionId>:<targetRoleId>`。
- 对外 eventId：`evt_` + 随机 UUID 去除连字符后的 32 位十六进制字符串。
- EventDelivery JSON 永不包含 dedupeKey。
- 重试先按 dedupeKey 找既有 StoryEvent，返回原 opaque eventId；同一事务和现有 `@@unique([eventId,userId])` 防止重复 delivery。
