# 《凯撒之死》Seedance 连续剧情与首尾帧合同 v2.0

项目：Our Many Worlds  
世界：凯撒——共和国最后的春天  
成片：20 秒，9:16，24 fps  
目标：生成一支**前后因果清楚、人物位置连续、镜头能自然衔接、真正像电影预告片**的宣传片，而不是一组各自好看但互不相干的 AI 片段。

---

## 0. 先说结论：v1.0 的核心问题不是“画面不够精美”，而是缺少连续性合同

现有 v1.0 把影片拆成多个独立生成镜头，但每个镜头只描述“这一段想发生什么”，没有把上一镜头结束时的精确状态，写成下一镜头开始时必须继承的状态。

结果是：

- 月桂冠在一个视频里已经落地，另一个视频里又从空画面中突然出现；
- 元老群演在撞击之后才进入，因果顺序颠倒；
- 凯撒原本应该从第一帧就躺在固定位置，却在生成过程中逐渐“长出来”或移动；
- 布鲁图斯、凯撒、群演、月桂冠和卷轴都在同一段里争夺模型注意力；
- 生成模型被同时要求处理物理碰撞、群体运动、焦点转移、人物表演、镜头运动、字幕和声音，最后每一项都只完成一部分；
- 前一镜尾帧与后一镜首帧没有共用同一张图片，所以剪辑处必然跳变。

### 对现有两个测试视频的直接审计

#### 《月桂冠坠地(1).mp4》

- 前约 0.5 秒只有空地面；
- 月桂冠约在 1 秒附近才出现；
- 羊皮纸随后才进入；
- 元老脚步约在 3 秒后才出现；
- 因此观众先看到“一个道具慢慢落下”，后来才看到“有人群”，完全没有“议事厅刚刚发生灾难”的即时冲击。

#### `img2video-277db2ef...mp4`

- 月桂冠从第一帧已经躺在地面，最重要的撞击动作没有发生；
- 凯撒身体在画面右侧逐渐显现，像生成出来而不是一直躺在那里；
- 群演运动方向不明确，只像在背景里移动；
- 画面自动出现英文文字，破坏后期统一字幕；
- 整段是“静态结果慢慢变化”，不是一个清晰的因果动作。

所以 v2.0 必须改成：

> **先生成整部片的关键首帧和尾帧，再让 Seedance 只负责两张已锁定画面之间的一项主要运动。**

# 1. v2.0 的七条硬规则

## 1.1 每个镜头只能有一个主要动作

正确：

```text
月桂冠垂直落下并弹起一次。
```

错误：

```text
月桂冠落下、纸张飞舞、群演逃跑、凯撒倒地、布鲁图斯抬手、摄影机追踪、焦点再切三次。
```

一个镜头可以有轻微环境运动，但只能有一个叙事主动作。

## 1.2 共享帧不能重新生成

例如：

```text
镜头 C01 的尾帧 = KF02
镜头 C02 的首帧 = 同一个 KF02 文件
```

不是“生成一张相似的图”，而是**把同一张 PNG 同时作为上一镜尾帧和下一镜首帧**。

## 1.3 黑场、字幕、音效、倒带和白闪全部后期完成

Seedance 不负责：

- 开头黑场；
- 英文字幕；
- Logo；
- 心跳；
- 对白混音；
- 完整倒带；
- 白闪转场。

模型只负责人物、道具和摄影机运动。

## 1.4 同一场景必须锁定摄影轴线

庞培议事厅内：

```text
凯撒倒地位置：画面右侧 65%—78%
布鲁图斯位置：画面中央偏左 45%—52%
月桂冠运动：从画面上方中央落下，向画面中央偏左滚动
庞培雕像：始终位于远景右侧
```

明亮柱廊与选择场景：

```text
凯撒永远位于画面左侧、暖光方向
卡西乌斯永远位于画面右侧、冷光方向
布鲁图斯永远位于中央或中央偏前
```

任何镜头不得左右镜像。

## 1.5 动作状态必须写成可量化状态

不要只写“手悬在中间”。要写：

```text
布鲁图斯右手位于画面中心，掌心向左前方，距离凯撒的手约 18 厘米，距离密信约 22 厘米，五指自然弯曲，尚未触碰任何对象。
```

## 1.6 所有人和道具必须从首帧就存在

不能让模型在视频中临时创造：

- 凯撒身体；
- 群演；
- 月桂冠；
- 密信；
- 军旗；
- 庞培雕像。

它们必须已经存在于首帧，只是发生运动或焦点变化。

## 1.7 每个剪辑点必须明确属于四种方式之一

```text
A. 连续动作：共用同一张桥接帧
B. 视线切：保持人物视线方向和屏幕方位
C. 形状匹配：月桂冠、手、蜡封等形状匹配
D. 遮挡/白闪/黑场：用于允许空间跳转
```

# 3. 全片连续性圣经

## 3.1 人物屏幕方向

| 人物 | 固定方向 | 固定意义 |
|---|---|---|
| 凯撒 | 画面左侧或中央偏左 | 暖光、信任、个人忠诚、荣耀 |
| 布鲁图斯 | 画面中央 | 选择者、两种价值的交界 |
| 卡西乌斯 | 画面右侧 | 冷光、共和国、制度压力 |

## 3.2 核心道具状态

### 月桂冠

```text
开场：古金色鎏金青铜，缺口和叶片排列始终一致。
撞击前：冠面与地面夹角约 20°。
第一次弹起：夹角约 35°，开口朝画面右后方。
滚动结束：开口略朝摄影机，位于前景中央偏左。
凯旋：戴在凯撒头上，叶片方向不变。
结尾：与开场相同方向下落，在距地面 3—5 厘米处冻结。
```

### 密信

```text
始终是同一张奶油色折叠纸草文书。
深红蜡封始终朝向摄影机。
亚麻绳交叉方向不能改变。
卡西乌斯用右手递出。
布鲁图斯始终用右手准备接触。
```

### 布鲁图斯右手

```text
开场：抬至胸腹之间，观察自己的手。
信任：与凯撒前臂相握。
递信：停在密信前约 8 厘米。
选择：悬在凯撒的手与密信之间。
高潮：先向凯撒方向偏移，再向前伸出，但不展示接触结果。
```

## 3.3 光线连续性

```text
死亡：冷灰、低饱和、暗酒红。
倒带后：暖石色、象牙白、深红恢复。
凯旋：暖金阳光。
信任：凯撒完全暖光；布鲁图斯半暖半冷。
卡西乌斯：冷灰侧光；蜡封是唯一暖色。
选择：左暖右冷，中央混合。
结尾：近黑，月桂冠保留古金和极弱淡紫反光。
```

# 10. 最重要的改变

v1.0 的思路是：

```text
给每个镜头一段详细文字，让模型自己决定首帧、过程和尾帧。
```

v2.0 的思路是：

```text
先决定首帧。
再决定尾帧。
上一镜尾帧与下一镜首帧共享。
模型只负责中间那一个动作。
字幕、倒带、白闪、黑场和声音由后期负责。
```

只有这样，20秒才会像一个连续发生的悲剧选择，而不是十几段各自独立的罗马短视频。
