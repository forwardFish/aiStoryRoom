# 0. 文档目的

这份文档不是把同一个“凯撒信任布鲁图斯—卡西乌斯递信—布鲁图斯犹豫”的故事更换十二个开头。

十二条短片采用十二套不同的叙事语法：

1. 伪历史新闻；
2. 青铜沙盘与残局棋局；
3. 战后复盘；
4. 政治牌局；
5. 架空历史博物馆；
6. 谍报档案；
7. 历史审判庭；
8. 舆论宣传战；
9. 铸币隐喻动画；
10. 古罗马壁画动画；
11. 三步残局挑战；
12. 六角色并行时钟。

这些视频分别调用不同玩家心理：

```text
历史好奇
角色代入
残局破局
预测与反制
信息不对称
身份与名誉
失败复盘
重玩优化
多人共同世界
改变历史的成就感
```

它们共同传达的产品事实是：

> 玩家不是重播一个固定的凯撒故事，而是进入公元前44年的罗马，扮演一个拥有自己目标、秘密、资源与风险的角色；你的动作会改变其他角色，其他角色的选择又会反过来改变你，最终所有人共同承担同一个罗马的结果。

# 1. 世界与产品事实边界

## 1.1 六个核心角色

```text
凯撒：权力中心。相信结束内战、债务与派系斗争，比维持旧制度形式更重要。
布鲁图斯：制度象征。希望限制个人权力，也不愿以另一场内战恢复共和国。
卡西乌斯：密谋核心。认为只要凯撒仍掌握军队与任命权，任何承诺都不可信。
安东尼：军团与行动力量。保护凯撒的法令、老兵与胜利者联盟，也在评估自己的未来。
德西穆斯：双面枢纽。拥有把凯撒带到元老院或改变路线的实际接近权。
西塞罗：合法性与公共叙事。没有公开合法性的胜利，只是另一种力量统治。
```

## 1.2 宣传片可以展示的架空结果

以下结果都只能作为“某一局可能出现的架空演算”，不能被表达为现实历史事实：

```text
凯撒存活，但共和国成为外壳；
凯撒死亡，安东尼控制广场与凯撒遗产；
军团提前分裂，罗马进入内战；
各方达成有限权力协议；
多方临时共和国勉强维持运转；
布鲁图斯被双方抛弃、流亡或成为制度内的反对者。
```

## 1.3 统一品牌承诺

十二条视频可以采用不同风格，但不得偏离三条承诺：

```text
你只控制自己的角色，不控制整个棋盘。
你的行动会触发其他角色的反应与反制。
历史结局不是唯一问题，第二天谁能让罗马继续运转同样重要。
```

## 1.4 统一品牌句

主品牌句：

```text
HISTORY GAVE THEM ONE CHANCE.
YOU GET ANOTHER.
```

中文：

```text
历史只给过他们一次机会。
你还有一次。
```

策略向品牌句：

```text
YOU CONTROL ONE ROLE.
NOT THE OUTCOME.
```

中文：

```text
你控制一个角色。
但没有人能独自控制结局。
```

# 2. 全系列统一制作规则

## 2.1 时间与结构

每条短片推荐22—30秒，不机械卡死20秒。完整因果优先于绝对时长。

通用结构：

```text
0—2秒：异常结果、问题或视觉钩子
2—8秒：建立规则与玩家处境
8—19秒：展示行动、反应与代价
19—24秒：留下未完成问题
24—30秒：品牌与角色化CTA
```

## 2.2 字幕密度

每条片最多5—7组核心屏幕文字。不要让观众同时处理长旁白、复杂画面和多行字幕。

字幕应满足：

```text
一句只传递一个概念；
每组英文尽量不超过8个词；
结果使用具体事件，不使用“影响力+3”之类抽象数值；
产品CTA必须包含动作词，如PLAY、ENTER、CHOOSE、OUTTHINK。
```

## 2.3 声音原则

不同风格使用不同声音母题：

```text
新闻：铜钟、羊皮纸拍击、传令官、群众骚动；
沙盘：石子落盘、青铜摩擦、军团脚步、低频计时；
复盘：时间线点击、节点告警、倒带与重排声；
牌局：卡牌落桌、印戒碰撞、筹码滑动、低声呼吸；
博物馆：安静空间、展柜继电器、讲解员低声旁白；
档案：封蜡、纸张翻页、笔尖划痕、锁扣闭合；
审判庭：木槌、回声、卷宗展开、审判合唱；
宣传战：浆糊、纸张撕裂、印章、街头呼喊；
铸币：熔炉、金属浇注、重锤、硬币旋转；
壁画：干裂颜料、刷笔、石墙震动、颜料流动；
残局：门闩、倒计时、棋子落位、评论挑战提示；
六时钟：齿轮、六种节拍、路线交汇、统一重击。
```

## 2.4 片尾统一原则

每条片最后必须明确这是可以进入并扮演的游戏，不要只像电影片尾。

推荐CTA：

```text
PLAY AS BRUTUS.
ENTER ROME.
OUTTHINK HISTORY.
TRY ANOTHER PLAN.
PLAY YOUR ROLE.
```

# 01｜《公元前44年的突发新闻》

## 核心定位

伪历史新闻快报。把玩家的行动包装成“罗马刚刚发生的突发新闻”，让观众先看见世界后果，再追查它来自哪一个秘密决定。

## 目标人群

历史爱好者、普通短视频用户、喜欢反事实历史与世界线变化的人。

## 一句话故事

布鲁图斯发出一封匿名警告后，凯撒改变路线、安东尼调动卫兵、卡西乌斯消失；罗马第二天的头条，全部由这一封信重新书写。

## 情绪曲线

```text
新闻异常
→ 连续升级
→ 追查源头
→ 发现源头是“你的行动”
→ 想亲自决定明天的头条
```

# 02｜《罗马不是一个故事，是一盘棋》

## 核心定位

高端青铜沙盘残局。用棋局直接告诉策略玩家：你只控制一个角色，其他五个角色会反制；两个显而易见的选择都可能失败，真正的挑战是找到第三条路。

## 目标人群

战棋、桌游、策略经营、历史模拟、《外交》、复杂决策类玩家。

## 一句话故事

布鲁图斯先警告凯撒，元老院被清洗；再加入卡西乌斯，军团分裂；棋盘第三次复位，一条历史从未走过的路线等待玩家完成。

## 情绪曲线

```text
识别残局
→ 尝试第一解
→ 遭遇反制
→ 尝试第二解
→ 仍然失败
→ 发现第三条路
→ “我来解”
```

# 03｜《你救了凯撒，为什么还是输了？》

## 核心定位

战后复盘 / 电竞赛后分析 / 历史战报。不是让观众先做选择，而是展示一次“目标成功、整局失败”的真实策略困境。

## 目标人群

重视行动顺序、时机、复盘、最优路线、反复重玩的硬核策略玩家。

## 一句话故事

布鲁图斯成功警告凯撒，却没先控制广场、安抚军团和约束安东尼；凯撒活了，罗马却失去了共和国。

## 情绪曲线

```text
以为胜利
→ 发现更大失败
→ 追查因果链
→ 定位错误时机
→ 想重新排列步骤
```

# 08｜《英雄，还是叛徒？》

## 核心定位

罗马街头宣传战。布鲁图斯尚未行动，凯撒阵营、共和阵营和愤怒市民已经在争夺他的名字与历史身份。

## 目标人群

关注舆论、政治传播、身份评价、名誉与后世记忆的用户。

## 一句话故事

同一面墙上，布鲁图斯被称为忠诚朋友、共和国救星和叛徒；他意识到，无论选择什么，都有人会用他的名字为自己的罗马服务。

## 情绪曲线

```text
公共叙事冲突
→ 身份被他人定义
→ 三个互斥标签覆盖同一张脸
→ 想夺回自己的名字
```

## 视觉与制作方式

- 使用古罗马墙面、手绘政治图像、浆糊、青铜印章与撕裂纸张；
- 不使用现代海报字体或摄影印刷，整体像古代公共公告与艺术化宣传画；
- 绝大部分可以通过平面动画完成；
- 可让西塞罗版本的公开声明在后续系列中成为第四种“合法性叙事”。

## 成功验收

观众应理解：

> “选择不只改变事件，也改变别人如何描述我；我想决定后世怎样记住布鲁图斯。”

# 09｜《每个选择都在铸造一个罗马》

## 核心定位

古代铸币厂的艺术隐喻。每一次选择都被铸成一枚双面硬币：一面是你想要的结果，另一面是你没有预见的代价。

## 目标人群

喜欢视觉艺术、收藏、分支结局、世界建构和象征性广告的用户。

## 一句话故事

第一枚硬币铸着“凯撒活着”，背面却是“元老院沉默”；第二枚铸着“凯撒死去”，背面是“军团分裂”；第三块空白金属等待布鲁图斯压下自己的答案。

## 情绪曲线

```text
创造感
→ 结果满足
→ 翻面发现代价
→ 第二次仍有代价
→ 空白未来等待玩家
```

|---:|---|---|---|---|


## 视觉与制作方式

- 使用熔炉、青铜、重锤、硬币浮雕和微缩罗马；
- 人物只以硬币头像与布鲁图斯的手出现；
- 视觉高级、稳定，不需要大量角色动画；
- 适合发展成每个世界独有的“结局收藏硬币”内容系列。

## 成功验收

观众应产生：

> “每个选项都只是硬币的一面。我想看看自己的选择会铸出怎样的罗马。”

# 10｜《墙上的历史醒了》

## 核心定位

古罗马壁画与2D手绘动画。让一幅已经画完的历史被观众触碰后重新流动，第四块空白画框等待玩家完成。

## 目标人群

动画、艺术、手绘、历史视觉文化、非真人广告受众。

## 一句话故事

观众触碰壁画里的月桂冠，凯撒之死开始倒流；布鲁图斯跨出既定画框，看见三个已画好的未来，而第四个未来仍是一片空白。

## 情绪曲线

```text
古老静止
→ 触碰后苏醒
→ 进入历史画中
→ 看见分支未来
→ 亲手补完空白
```

# 11｜《三步破局》

## 核心定位

评论区互动残局。把宣传片变成一道真正有状态、有资源、有反制的策略题，让用户先在评论区给出第三步，再进入游戏验证。

## 目标人群

策略挑战、残局题、短视频互动、评论参与、桌游与战棋用户。

## 一句话故事

凯撒距离元老院只剩三步；玩家已经延迟会议、调开部分卫兵，却让卡西乌斯改线、安东尼起疑。现在只剩最后一步，应该公开对决、暴露一个密谋者，还是争取西塞罗？

## 情绪曲线

```text
明确残局
→ 给出资源与约束
→ 展示两步及反制
→ 留一个真实未解问题
→ 激发评论与验证欲
```

# 12｜《六个人，同时改变罗马》

## 核心定位

六角色并行时钟 / 多线交叉剪辑。直接展示共同世界的核心：布鲁图斯思考时，其他五个角色并不会暂停；每个人都在用自己的目标推动同一个三月十五日。

## 目标人群

多人博弈、社交策略、异步游戏、AI补位、群像叙事与复杂系统用户。

## 一句话故事

六只青铜时钟同时开始：凯撒决定是否出席会议，卡西乌斯换信使，安东尼调卫兵，德西穆斯控制路线，西塞罗准备公开声明，布鲁图斯仍在判断；一封秘密消息改变三个人的下一步，所有路线最终汇入同一座元老院。

## 情绪曲线

```text
多人同时启动
→ 我无法让别人暂停
→ 一个动作改变多条路线
→ 其他人的反应回到我身上
→ 想预测共同结局
```

## 视觉与制作方式

- 六只时钟可用人物硬币、齿轮与地图线条制作；
- 不要求六名真人同时生成；
- 适合使用分屏、图形动画与少量人物短镜头；
- 发布前必须确认产品真实支持六角色同时行动、AI补位或多人共同世界，避免过度承诺；
- MVP阶段可把文案写成`SIX ROLES`而不是`SIX HUMAN PLAYERS`。

## 成功验收

观众应理解：

> “我不是在和一段等我选择的静态剧情互动。其他角色会同时行动，并用自己的选择改变我的局。”

# 14. MVP阶段实际制作建议

只制作三条时，建议选择三种完全不同的用户入口：

## 第一条｜情绪与角色入口

```text
真人电影化《他信任你》或现有《凯撒之死》主宣传片
```

它解决：

> 为什么我要在情感上成为布鲁图斯？

## 第二条｜历史结果入口

```text
《公元前44年的突发新闻》
```

它解决：

> 我的动作是否真的会改写整个时代，而不是只改一句剧情？

## 第三条｜策略破局入口

```text
《罗马不是一个故事，是一盘棋》
```

它解决：

> 这个游戏有没有值得我认真思考、复盘和重玩的策略深度？

三条组合起来分别覆盖：

```text
人物情绪
世界后果
策略挑战
```

# 15. 第二批内容建议

当第一批确认有人停留、评论与点击后，再制作：

# 16. 统一验收标准

任何一条片发布前，至少满足以下条件：

```text
□ 前2秒能独立成立，不依赖用户先了解凯撒历史。
□ 观众能知道这不是固定电影，而是可参与的游戏。
□ 展示的是具体行动和具体后果，不是抽象“世界发生改变”。
□ 没有把凯撒拍成简单暴君，也没有把卡西乌斯拍成简单恶人。
□ 至少有一个“我觉得我能做得更好”的心理钩子。
□ 片尾CTA明确包含PLAY、ENTER、CHOOSE或OUTTHINK。
□ 架空结局被表达为可能时间线，而不是现实史实。
□ 不承诺当前产品尚未支持的多人同步、完全自由或无限结局。
□ 看完后，用户能在脑中提出一个具体问题，而不是只觉得画面好看。
```

十二条视频各自最理想的脑内问题：

```text
01：哪一条头条会成为我的历史？
02：两个明显选择都失败，我能找到第三条路吗？
03：我究竟在哪一个时机犯错？
04：我的名誉应该押在哪一边？
05：我的一局会留下哪件不存在的文物？
06：我该公开多少信息、隐藏多少意图？
07：我愿意为哪一种后果承担责任？
08：我想让后世怎样定义布鲁图斯？
09：我的选择会铸出怎样的罗马？
10：第四块空白壁画里会发生什么？
11：最后一步应该怎么走？
12：我行动以后，另外五个角色会怎样反制？
```

# 17. 最终创作原则

Our Many Worlds的宣传片不应只说：

```text
你可以改变历史。
```

更有吸引力的表达是：

```text
你可以改变历史，
但历史不是一条只等你选择的路。
其他人有自己的目标、秘密和下一步。
你改变他们，他们也会改变你。
```

这套十二条短片最终要让不同类型的用户分别产生三种冲动：

```text
角色玩家：换成我，我会怎么选？
策略玩家：这盘局看起来很难，但我觉得我能解。
多人博弈玩家：我想知道别人会怎样理解并反制我的行动。
```

统一收束句：

```text
HISTORY GAVE THEM ONE CHANCE.
YOU GET ANOTHER.
```

# 18. 版本说明

本文件中的人物关系、六角色结构、信息不对称、架空结局方向与“谁能让罗马在第二天继续运转”的核心命题，均以《凯撒：共和国最后的春天》的现有产品与剧本框架为边界。

本文件新增内容属于宣传创意扩写，包括新闻、沙盘、博物馆、审判庭、铸币和壁画等视觉叙事形式。它们不是新增游戏玩法，也不应被前台宣传误解为当前产品已经提供对应的博物馆、扑克或铸币系统。
