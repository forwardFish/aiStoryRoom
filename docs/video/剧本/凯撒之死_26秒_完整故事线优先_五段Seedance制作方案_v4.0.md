# 0. 本次修改结论

v3.0 最大的优点，是把十几次独立生成收敛为少量连续母片；但它为了把成片压进20秒、把生成次数压到4次，牺牲了几个决定故事是否成立的关键环节：

```text
布鲁图斯面对凯撒死亡后的负罪与不确定；
凯撒确实受到罗马人拥护，而不是只从一群模糊群众旁边经过；
凯撒说出信任之后的停顿；
凯撒为什么危险；
救凯撒和背叛凯撒分别可能造成什么灾难；
最终三角画面为什么会出现已经离开的凯撒。
```

v4.0 不再把“20秒”作为硬约束，而是把成片调整到约26秒，并改成：

```text
Seedance 01：悲剧终点——凯撒已经死去
静态剧情帧：布鲁图斯看向自己的右手
后期倒带：历史重新开始
Seedance 02：权力顶峰——凯撒真正受到罗马拥护
Seedance 03：私人信任——凯撒握住布鲁图斯并离开
Seedance 04：政治警告——卡西乌斯递出密信
静态过渡帧：现实空间转为布鲁图斯主观选择空间
Seedance 05：两种未来——布鲁图斯作出未完成的决定
复用 Seedance 01：月桂冠停在触地之前
现有 Logo：PLAY AS BRUTUS.
```

最终需要：

```text
5 次 Seedance 主生成
2 张静态剧情关键帧
1 段月桂冠素材复用
1 段现有 Logo
```

它仍然远少于原来的十几次生成，但不再为了省一次生成而删掉故事。

# 1. 这支宣传片要讲清楚的完整故事

## 1.1 故事起点

罗马刚刚结束内战。

凯撒击败了所有主要对手。他拥有军团、声望、民众支持与几乎无人能够制衡的权力。普通市民相信他结束了混乱，老兵相信他会兑现承诺，许多人认为只有凯撒能够让罗马继续运转。

但凯撒已经成为终身独裁官，并准备发动新的远征。

反对者担心：

> 只要凯撒再获得一次胜利，共和国就只会剩下名字。

## 1.2 布鲁图斯为什么痛苦

布鲁图斯不是凯撒的普通政敌。

凯撒曾经宽恕他、恢复他的地位，并真诚地信任他。对布鲁图斯来说，凯撒既可能是共和国最后的拯救者，也可能是共和国最后一个无法被限制的人。

卡西乌斯需要布鲁图斯加入，不只是需要他的行动，更需要他的名字赋予阴谋“拯救共和国”的正当性。

因此，布鲁图斯面对的不是：

```text
杀一个坏人
或
救一个好人
```

而是：

```text
救下信任自己的朋友，共和国可能慢慢死去；
背叛信任自己的朋友，罗马可能立即陷入战争。
```

## 1.3 宣传片的完整心理路线

观众必须依次经历：

```text
凯撒已经死了。
↓
布鲁图斯可能做错了。
↓
历史给了他第二次机会。
↓
凯撒确实受到人民拥护。
↓
凯撒亲口告诉布鲁图斯：我信任你。
↓
卡西乌斯告诉他：凯撒再赢一次，罗马就会跪下。
↓
救凯撒，共和国可能死亡。
背叛凯撒，罗马可能燃烧。
↓
布鲁图斯的手已经伸出，但答案没有出现。
↓
这一次，玩家成为布鲁图斯。
```

只要其中任何一环缺失，观众就可能只看到：

```text
一顶月桂冠掉了；
两个罗马人在说话；
有人递了一封信；
最后出现一个Logo。
```

v4.0 的所有时间和镜头，都为这条完整因果链服务。

# 2. 完整故事线验收标准

影片结束后，一个完全不了解罗马历史的观众，也应该能回答：

| 问题 | 影片必须给出的答案 |
|---|---|
| 谁死了？ | 凯撒。 |
| 玩家是谁？ | 布鲁图斯。 |
| 凯撒与玩家是什么关系？ | 凯撒真正信任布鲁图斯。 |
| 为什么有人想救凯撒？ | 他受到人民拥护，带来了秩序，也把布鲁图斯当作朋友。 |
| 为什么有人想阻止凯撒？ | 他已经强大到接近无人可以限制，再一次胜利可能让罗马屈服。 |
| 为什么不能简单选“好人”？ | 救他可能毁掉共和国；背叛他可能引发战争。 |
| 影片为什么不公布答案？ | 因为答案要由玩家进入游戏后作出。 |
| 这是什么产品？ | 一个让玩家扮演布鲁图斯、改变历史局势的游戏。 |

## 2.1 情绪上的二选一，不等于玩法只有两个选项

宣传片为了形成最强情绪，会把矛盾压缩成：

```text
凯撒
VS
共和国
```

但游戏内部仍然可以允许第三条道路：

```text
警告凯撒；
加入卡西乌斯；
欺骗双方；
延迟会议；
制造有限权力协议；
寻找历史没有发生过的解决方案。
```

第一条宣传片不解释完整玩法，只负责让观众产生：

> 换成我，我会怎么做？

# 4. 本版本为什么比v3.0更完整

## 4.1 恢复布鲁图斯的负罪环节

旧v3.0从月桂冠滚动直接进入倒带，观众知道凯撒死了，却不知道：

```text
这件事与“我”有什么关系？
```

v4.0增加约0.9秒的布鲁图斯关键帧：

```text
他先看向凯撒静止的右手，
再低头看向自己的右手。
```

字幕：

```text
HE TRUSTED YOU.
```

这会把观众从历史旁观者变成关系当事人。

## 4.2 恢复独立的凯旋大道事件

凯撒不能只是从柱廊入口后面的一小群人中走出来。

观众必须先看见：

```text
市民向他伸手；
老兵注视他；
军旗与鹰标在身后；
他是一个真正受到罗马拥护的人。
```

否则“救凯撒”没有国家秩序层面的理由，只剩私人感情。

## 4.3 给“I trust you, Brutus.”真正的停顿

凯撒说完后，二人仍保持前臂相握约0.45—0.60秒。

这段时间不出现新字幕，不发生新动作。

观众要有时间感受到：

> 开场倒下的那只手，曾经真诚地握住布鲁图斯。

## 4.4 把政治危险说具体

卡西乌斯对白改为：

```text
One more victory...
and Rome kneels.
```

它让普通观众不需要理解“终身独裁官”也能明白：

```text
凯撒已经赢过太多次；
如果他再次胜利，罗马可能再无制衡。
```

## 4.5 明确两个选择都可能造成灾难

高潮旁白：

```text
Save him...
and the Republic may die.

Betray him...
and Rome may burn.
```

这样不是“友情对冷酷阴谋”，而是：

```text
秩序可能变成独裁；
反抗可能变成战争。
```

## 4.6 最终三角画面是心理空间，不是物理瞬移

凯撒在上一段已经离开。

因此高潮中左侧出现的凯撒，不是他突然走回来，而是布鲁图斯在密信前看见的：

```text
私人信任的记忆；
保存凯撒的可能未来；
自己可能背叛的人。
```

v4.0强制使用独立静态过渡帧KFG02，将现实侧廊转为“布鲁图斯的主观选择空间”。

# 6. 全片连续性圣经

## 6.1 固定屏幕方向

```text
凯撒：画面左侧或中央偏左；暖光；信任、荣耀、个人秩序。
布鲁图斯：画面中央；光影交界；选择者。
卡西乌斯：画面右侧；冷光；共和国、制度压力。
```

任何镜头不得左右镜像。

## 6.2 三只手的连续故事

### 凯撒右手

```text
开场：静止在月桂冠后方，戴青铜印戒。
信任：握住布鲁图斯的右前臂。
主观选择空间：从左侧向布鲁图斯伸出。
```

### 布鲁图斯右手

```text
悲剧终点：抬到胸腹之间，像第一次看见它。
信任：反握凯撒右前臂。
密信：停在蜡封前约8厘米。
高潮：悬在凯撒的手与密信之间。
结尾：向前伸出，但不显示接触结果。
```

### 卡西乌斯右手

```text
从托加内取出密信；
蜡封朝向摄影机；
动作稳定、不逼迫；
高潮始终保持递信状态。
```

## 6.3 月桂冠状态

```text
开场下落：距地面约35厘米，冠面倾斜20度。
撞击后：弹起一次。
滚动结束：开口略朝摄影机。
凯旋：戴在凯撒头上，叶片方向不变。
结尾：同一角度重新下落，在距地面3—5厘米停止。
```

## 6.4 光线变化

```text
死亡：冷灰、低饱和、暗酒红。
罪疚：布鲁图斯半冷半暖。
倒带：冷色迅速恢复为暖石色。
凯旋：暖金下午光。
信任：凯撒全暖光，布鲁图斯位于光影交界。
卡西乌斯：冷灰侧光，深红蜡封为唯一暖色。
主观选择：左暖右冷，中央混合。
结尾：近黑，月桂冠保留古金与极弱淡紫反光。
```

# 22. 失败时的最小重做策略

## 22.1 Seedance 01失败

只检查：

```text
月桂冠是否真实下落、弹起和滚动；
凯撒是否从第一帧就倒地；
布鲁图斯与群演是否从第一帧就存在；
背景是否稳定。
```

不要因为背景群演表情不完美而重做月桂冠物理正确的版本。

## 22.2 Seedance 02失败

优先保留：

```text
凯撒身份稳定；
道路中央清楚；
群众在两侧；
红旗最终完全遮挡镜头。
```

群众动作可以后期减速或使用静态分层，不要求每个人都完美。

## 22.3 Seedance 03失败

握臂手部是最高优先级。

若手部无法稳定：

```text
先单独生成握臂静态桥接帧；
Seedance只负责接近与松开；
握住后的0.55秒直接用静态帧轻推。
```

## 22.4 Seedance 04失败

卡西乌斯不能凭空出现。

若模型仍让他中途生成：

```text
把卡西乌斯完整人物直接合成进BRIDGE 02首帧柱后；
视频提示词只要求他走出半步与递信。
```

## 22.5 Seedance 05失败

手部接触结果绝不能出现。

若手指错误：

```text
在布鲁图斯手刚开始移动时提前切黑；
不要求生成完整伸手轨迹；
使用后期方向性模糊完成最后0.15秒。
```

# 25. 最终判断

v4.0 不再以“少一段Seedance”或“必须刚好20秒”为最高目标。

它的优先级是：

```text
第一：故事因果完整；
第二：人物关系有情感重量；
第三：政治两难对普通观众也能理解；
第四：首尾帧与空间连续；
第五：在不破坏前四项的前提下控制生成次数与时长。
```

最终方案为：

```text
5段Seedance主母片
+2张静态剧情帧
+1次月桂冠素材复用
+现有Logo
≈26秒完整宣传片
```

这不是把20秒脚本简单拉长，而是补回了故事成立所必须的因果、关系、危险和后果。
