# 《凯撒之死》20秒宣传片｜四段 Seedance 连续长镜头制作方案 v3.0

项目：Our Many Worlds  
世界：凯撒——共和国最后的春天  
成片时长：20 秒  
画幅：9:16  
生成策略：**4 次 Seedance 主生成 + 1 次现有 Logo 素材 + 第 1 段素材复用**  
目标：保持故事完整、人物关系清楚、空间连续，同时把生成次数从十几次压缩到 4 次。

---

# 0. 先给结论

当前问题不在于故事本身，而在于把“电影剪辑节拍”错误地等同于“Seedance 生成任务”。

原 v2.0 中的 13 个镜头，可以继续作为剪辑层面的节拍参考，但**不能对应 13 次生成**。Seedance 每次至少生成约 4 秒，如果逐镜头生成，会得到 50—60 秒原始素材，成本高、衔接难、人物和建筑更容易漂移。

最终方案改为：

```text
Seedance 01：凯撒已死 + 月桂冠坠落
Seedance 02：凯撒从欢呼中走来 + 信任布鲁图斯
Seedance 03：凯撒离开 + 卡西乌斯递出密信
Seedance 04：布鲁图斯面对两种罗马 + 伸手前切黑
复用 Seedance 01：月桂冠在触地前停止
现有 Logo 视频：结束
```

也就是：

```text
4 段 Seedance 主母片
+ 1 段既有 Logo
= 20 秒完整成片
```

故事核心不变：

```text
凯撒已死
→ 历史倒流
→ 凯撒信任布鲁图斯
→ 卡西乌斯要求他拯救共和国
→ 布鲁图斯必须选择
→ 月桂冠在触地前停止
→ 选择交给玩家
```

# 1. 需要调整的不是故事，而是空间和镜头组织

## 1.1 原版为什么会碎

原方案有五个独立场景：

```text
庞培议事厅
凯旋大道
明亮主柱廊
冷色秘密侧廊
命运十字柱廊
```

每次换空间，Seedance 都要重新理解：

- 建筑；
- 人物站位；
- 摄影轴线；
- 光线；
- 人物服装；
- 道具位置。

这会造成明显的“AI短片拼接感”。

## 1.2 v3.0 只保留两个物理空间

### 空间 A：庞培议事厅

承担：

```text
凯撒已死
月桂冠坠落
时间倒流
结尾月桂冠悬停
```

使用：

```text
BG02｜庞培议事厅-低机位地面背景.png
BG09｜月桂冠结尾专用暗色地面背景.png
```

### 空间 B：命运十字柱廊

承担整个中段：

```text
左侧暖光入口：市民、老兵、凯撒的荣耀
中央：布鲁图斯与凯撒建立信任
右侧冷色侧廊：卡西乌斯与密信
最终：布鲁图斯站在左右两种罗马之间
```

使用：

```text
BG08｜命运十字柱廊-纯空间背景.png
```

BG08 不再只在高潮出现，而是成为中段的统一主场景。这样：

- 凯撒从左侧暖光与人群方向进入；
- 布鲁图斯一直站在中央；
- 卡西乌斯从右侧冷廊进入；
- 最终选择不需要再换场景；
- 三段 Seedance 可以共享同一建筑与摄影轴线。

# 3. 新版本删掉或合并了什么

## 3.1 不再独立生成“凯旋大道”镜头

凯撒的受拥护感不删除，而是放进 Seedance 02 的左侧暖光入口：

```text
凯撒从欢呼的市民与老兵之间走入柱廊
→ 人群仍能看见
→ 他径直走向布鲁图斯
```

这样观众依然能理解凯撒受人拥护，却不用再换一次场景。

## 3.2 不再独立生成“凯撒回望”镜头

回望被压缩进 Seedance 02 尾部：

```text
凯撒松开布鲁图斯
→ 走向暖光中的议事厅入口
→ 轻微侧头确认
```

不再单独生成一条视频。

## 3.3 不再独立生成暖光与冷光闪回

凯撒、卡西乌斯和“两种罗马”同时存在于统一柱廊空间：

```text
左侧：凯撒、暖光、人群、军旗
右侧：卡西乌斯、冷光、密信、沉默元老
中央：布鲁图斯
```

观众不需要额外闪回，也能立即理解冲突。

## 3.4 不再单独生成布鲁图斯面部与手部两条视频

Seedance 04 从中景拉到三角构图，再通过后期裁切同一段视频得到：

```text
布鲁图斯眼神近景
布鲁图斯右手近景
三人关系全景
```

一段母片可以剪出三个节拍。

# 4. 全片连续性合同

## 4.1 固定屏幕方向

```text
凯撒：始终位于画面左侧或中央偏左，对应暖光。
布鲁图斯：始终位于画面中央，是选择者。
卡西乌斯：始终位于画面右侧，对应冷光。
```

任何一段不得镜像。

## 4.2 固定空间

```text
Seedance 02、03、04 都使用同一个 BG08。
柱子位置、地面纹理、左右通道、光线方向不得改变。
```

## 4.3 固定道具

### 月桂冠

```text
始终使用 P01。
叶片数量、缺口、开口方向、金属磨损保持一致。
```

### 密信

```text
始终使用 P02。
深红蜡封朝向摄影机。
亚麻绳交叉方向不变化。
```

## 4.4 只有两个强制共享桥接帧

```text
BRIDGE 01：凯撒离开、布鲁图斯留在中央
Seedance 02 尾帧 = Seedance 03 首帧

BRIDGE 02：卡西乌斯递信、布鲁图斯手停在8厘米外
Seedance 03 尾帧 = Seedance 04 首帧
```

不再制作二十多张关键帧。

```text
古罗马晚期共和国，公元前44年，电影级超写实历史政治惊悚片。人物脸、年龄、身高、体型、发型、服装严格跟随参考图。建筑结构、柱子位置、地面纹理和光线方向不得漂移。
```

# 6. Seedance 01｜死亡循环母片

## 6.1 用途

一段素材承担三处成片：

```text
开场死亡钩子
时间倒流
结尾月桂冠悬停
```

## 6.2 建议生成

```text
生成时长：5秒
成片使用：约5.15秒，分三次复用
```

## 6.3 Mixed 映射

```text
{{Mixed 1}} = BG02｜庞培议事厅-低机位地面背景.png
{{Mixed 2}} = P01｜凯撒金色月桂冠.png
{{Mixed 3}} = 凯撒.png
{{Mixed 4}} = 布鲁图斯.png
{{Mixed 5}} = G01-A｜元老院群演-白背景设定图版.png
```

## 6.4 首帧合同

```text
摄影机距离石材地面约10厘米，28mm超低机位，严格使用{{Mixed 1}}的庞培议事厅。

{{Mixed 2}}月桂冠从第一帧就位于画面上方中央，距离地面约35厘米，冠面与地面夹角20度，开口朝画面右后方，正在下落。

{{Mixed 3}}凯撒从第一帧就已经倒在画面右侧中景，身体大部分被固定披风和托加遮挡，不展示伤口，只露出右前臂和印戒。身体全程不移动、不生成、不变形。

{{Mixed 4}}布鲁图斯从第一帧就站在远景中央偏左的两根柱子之间，完全静止。

{{Mixed 5}}元老群演从第一帧就已经位于中远景两侧，正在向两边后退，不能在月桂冠落地以后才出现。

冷灰、暗酒红、低饱和。月桂冠为唯一锐利焦点。
```

## 6.5 视频提示词

```text
【超低机位贴地跟拍】【月桂冠坠落与滚动】【背景人物只做辅助运动】

场景：严格使用{{Mixed 1}}庞培议事厅低机位背景，保持地面、柱子、长凳、庞培雕像和光线方向完全不变。

人物：{{Mixed 3}}凯撒始终固定倒在画面右侧中景；{{Mixed 4}}布鲁图斯始终站在远景中央偏左；{{Mixed 5}}元老群演从第一帧就已存在，只向两侧后退一到两步。

核心动作时间线：
0.0—1.1秒：{{Mixed 2}}月桂冠高速垂直落下，撞击石材地面，弹起一次。金属叶片产生真实颤动和清脆碰撞。
1.1—2.8秒：月桂冠向画面深处滚动约60厘米，速度逐渐降低。摄影机保持10厘米高度，沿同一轴线跟随约25厘米。
2.8—5.0秒：月桂冠停在前景中央偏左，开口略朝摄影机。摄影机停止。焦点由月桂冠轻微转向凯撒静止的右手，再到远处布鲁图斯；不能做三次明显拉焦。

背景群演只做克制退避，不奔跑，不穿过前景。凯撒和布鲁图斯完全不动。不要让纸张中途凭空出现，不生成文字。

尾帧：月桂冠已经停止；凯撒位于右侧中景；布鲁图斯位于远景中央偏左；元老退到两侧，形成清晰纵深。
```

## 6.6 后期使用方式

### 开场：00:00.15—00:02.25

使用正向片段：

```text
月桂冠下落
→ 撞击
→ 滚动
→ 凯撒与布鲁图斯显现
```

### 倒带：00:02.25—00:03.70

复制同一段素材并反向：

```text
月桂冠从停止位置反向滚回
→ 弹起
→ 向上飞离画面
→ 元老脚步反向归位
```

速度调整到约180%—260%，尾部接2—3帧白闪。

不要生成“凯撒从地上站起来”的AI动作。白闪后直接切到活着的凯撒，更高级也更稳定。

### 结尾：00:16.60—00:18.20

再次复用同一素材的“月桂冠触地前”部分：

```text
从距离地面约18厘米开始
→ 降速到40%—50%
→ 距地面3—5厘米时冻结
→ 定格10—12帧
```

后期压暗背景，并在月桂冠边缘增加极弱品牌淡紫反光。

# 8. Seedance 03｜信任离开，阴谋进入

```text
凯撒离开
→ 布鲁图斯听见脚步并转身
→ 卡西乌斯从冷廊走出
→ 密信进入两人之间
```

## 8.2 建议生成

```text
生成时长：5秒
成片使用：00:08.20—00:12.50，共4.3秒
```

## 8.3 Mixed 映射

```text
首帧 = BRIDGE_01_Caesar_Leaves.png
{{Mixed 1}} = BG08｜命运十字柱廊-纯空间背景.png
{{Mixed 2}} = 布鲁图斯.png
```

## 8.4 关键约束

卡西乌斯不能在视频中凭空出现。

首帧时，他已经位于右侧冷廊前景石柱后方，只露出很少的肩部和托加轮廓，观众不一定注意到，但模型必须知道他已经存在。

凯撒也不能突然消失。他在首帧位于左侧暖光中远景，随后继续向深处走出清晰区域。

## 8.5 视频提示词

```text
【同一柱廊连续镜头】【摄影机跟随布鲁图斯转向】【卡西乌斯递信】

首帧：严格使用BRIDGE_01_Caesar_Leaves.png，不重新生成相似画面。

场景：保持{{Mixed 1}}命运十字柱廊的所有柱子、地面、左右通道和光线完全一致。

人物：{{Mixed 2}}布鲁图斯位于中央；{{Mixed 4}}凯撒在左侧暖光中远景继续离开；{{Mixed 3}}卡西乌斯从第一帧就藏在右侧冷廊石柱后，不能中途生成。

动作时间线：
```

```text
复制月桂冠触地前约0.5秒素材

背景整体压暗

```

后期加入：

```text
旁白：This time... the choice is yours.
```

这比重新生成一条月桂冠视频更稳定，因为：

- 月桂冠一定是同一顶；

# 17. 最终判断

脚本不需要推倒重写，但需要从“五个地点、十几个生成镜头”收敛为：

```text
一个死亡循环
一个连续的柱廊选择故事
一个Logo结尾
```

新的观众体验仍然完整：

```text
我先看见凯撒已经死了。
历史把我送回他仍然活着的时刻。
他走过人群，来到我面前，说他信任我。
他刚刚离开，卡西乌斯便从阴影里递来密信。
凯撒在左，卡西乌斯在右，我站在中央。
我的手已经伸出去。
但历史在答案出现前停止。
```

这才是适合 20 秒、适合 Seedance、也适合 MVP 宣传片的连续剧情结构。
