# 一、审核预览

## 1. 全剧一句话主命题

> **当朝廷把国库、军饷和改桑期限压进一场洪水，掌兵的人、掌印的人和掌粮船的人，必须决定自己究竟是在救浙江，还是在借“大局”把代价转交给另一个人。**

## 2. 三名永久真人为什么缺一不可

| 真人席位 | 他掌握的不是抽象权限，而是 | 他无法替代另外两席的原因 |
|---|---|---|
| 浙江总督·胡宗宪 | 军令、海防、跨府县调度、领衔奏报和公开政治责任 | 命令必须由省府落地，也必须有商会的船粮才能成为现实；他可以决定“国家要做什么”，不能单独决定事情是否做成 |
| 浙江省府·郑泌昌 | 印信、府县官吏、差役、民夫、田契登记和首版公文 | 总督可以越级下令，商会可以拒绝资源，但只有省府能让命令进入县里，并决定同一批粮在档案中叫赈济、借贷还是买田 |
| 江南商会·沈一石 | 船、粮、船夫、仓储、信用、合同、商路和原始账册 | 官府可以征、可以逼、可以许诺，却不能凭空制造物资；沈一石决定政策是否真正触到灾民，也决定官府的善意能否被现实支付 |

三席构成一条不可拆分的历史因果：

```text
胡宗宪决定军政方向
→ 郑泌昌决定命令如何进入地方机器
→ 沈一石决定船粮信用是否实际投入
→ 沈一石留下的清单与后果反过来改变省府口径
→ 省府的签押与执行结果再迫使胡宗宪承担或切割
```

三人长期冲突不是“谁善谁恶”，而是三种都不能轻易放弃的生存原则：

- 胡宗宪相信必须保住仍能做事的权力；
- 郑泌昌相信机器一旦断裂，所有人都会先拿地方官祭旗；
- 沈一石相信没有边界的救急，最终只会把私人信用变成权力随时可以没收的余额。

# 三、三名永久真人的七章人物弧线

## A. 浙江总督·胡宗宪：从“维持可做事的位置”到“愿让真相审问自己”

### 初始立场

**SOURCE_CONFIRMED：**胡宗宪依赖严氏政治网络与军饷，却同时承担东南海防和浙江民生。他相信真正能做事的人必须留在位置上，许多坏政策可以在地方执行中被修正。

### 想保住什么

- 浙江仍然可治理，而不是灾后只剩互相推责；
- 东南海防和戚家军的有效战力；
- 马宁远等能做事、也曾为他承担的人；
- 对灾情与第一道奏疏的领衔权；
- “大局”仍能包含百姓，而不是成为压低层承担的借口。

### 最害怕什么

- 为救灾抽空海防，最后洪水和倭患两边都失；
- 自己对严氏的依赖使所有正确行动都失去可信度；
- 下属以忠诚之名替他一个个去死；
- 他一生的权衡最终被证明只是替更大的错误延长寿命。

### 与另外两人的不可调和冲突

- 对郑泌昌：胡要求立刻停止危险执行，郑要求胡先把共同责任写在同一张纸上；
- 对沈一石：胡要求危局之下船粮先救人，沈要求救人也必须有签收、归还与损失责任。

### 七章变化

| 章节 | 胡宗宪的变化 |
|---|---|
| N1 | 第一次承认“一纸军令”不等于送达；他必须说清放弃哪里、谁具名、海防空缺由谁补 |
| N2 | 从控制灾情转向承担叙述；是否领衔一份会牵连自己和严氏关系的奏疏成为人格选择 |
| N3 | 发现饥饿不会服从军令；必须依赖一个不能被他完全命令的商人，并为这种依赖承担政治代价 |
| N4 | 面对“通倭”死局；若停刑可能被指包庇，若放任则亲手让一场死刑封住灾情和商路真相 |
| N5 | 认识到“粮船到了”不等于灾民得到粮；军队保护哪一种卸粮方式，本身就是政治选择 |
| N6 | 过去用于维持军务的财政与商路开始成为查封对象；他必须决定保钱、保账、保人还是保自己 |
| N7 | 不再只问哪一种说法最能保住浙江，而问哪一种事实值得由自己盖印，即使它会审问自己 |

### 最终可能得到与失去

他可能保住部分军队、治理能力和下属信任，也可能失去严氏支持、总督官位、军饷甚至一生经营的政治道路。最终评判不预写“忠臣胜利”，而依据他实际承担过哪些公开责任、保护过哪些证人与百姓、又把哪些代价转给了别人。

## B. 浙江省府·郑泌昌：从“机器必须继续运转”到“承认机器做过什么”

### 初始立场

**SOURCE_CONFIRMED：**郑泌昌掌握省府印信和地方执行链，并知道借汛淹田、以粮买田的危险意图。他相信行政机器一旦公开断裂，府县、差役、民夫和地方秩序会先崩，自己也会成为最方便的责任终点。

### 想保住什么

- 省府印信和地方行政机器；
- 自己与家人的安全；
- 上级政治保护不在出事后突然切断；
- 第一版公文和地方档案的解释权；
- 不让全部责任只停在“地方擅行”四个字上。

### 最害怕什么

- 严世蕃、何茂才、杨金水在灾后把他独自切出；
- 撤令证明原令有问题，不撤又让伤害继续；
- 马宁远、经手书吏和商会清单把执行链逐段拼回；
- 总督保住清名，中央保住体面，最终只有省府承担全部罪责。

### 与另外两人的不可调和冲突

- 对胡宗宪：总督能够从更高处要求“立刻救人”，真正撤换府县命令并留下印信的是省府；
- 对沈一石：省府需要商会资源，却还掌握把同一批粮写成赈、借、捐或买田的登记权。

### 七章变化

| 章节 | 郑泌昌的变化 |
|---|---|
| N1 | 试图保持旧执行链，第一次看见总督军令、商船清单和清流见证能让“省府从未下过危险命令”无法成立 |
| N2 | 掌握第一版奏稿；每一个删改都可能救他，也可能成为证明他知道什么的痕迹 |
| N3 | 三日断粮把行政语言变成仓门外的人群；他必须决定征谁的粮、先救哪一县、粮价与债务由谁承担 |
| N4 | 发现一场通倭案确实能迅速恢复秩序，却也能反过来吞掉省府自己的经手人与证据 |
| N5 | 田契、公仓和接收登记让他无法再说自己只是转达；灾民失田与否真正经过他的印信 |
| N6 | 把沈一石写成唯一奸商最能自保，却会让八箱账册中的上层责任一起消失；他开始被自己设计的替罪链反噬 |
| N7 | 必须决定维持一套能保官却解释不了证据的口径，还是承认省府实际执行并争取共同责任 |

### 最终可能得到与失去

他可能保住官位和行政体系，也可能失去印信、上级保护、家庭安全与“我只是执行”的自我安慰。高质量结局不是把他洗白，而是判断他何时停止让机器替自己说话，并是否愿意把真实执行写入可追索记录。

## C. 江南商会·沈一石：从“账算得清便能自保”到“决定哪一种真相值得用全部身家支付”

### 初始立场

**SOURCE_CONFIRMED＋REASONABLE_ADAPTATION：**沈一石拥有船、粮、船夫、信用与商路；本项目现有 N1 信息边界规定，他开场不知道完整借汛买田计划，只知道多路官府同时征用资源。他相信银、船、账册和契约至少能迫使官府承认商人做过什么。

### 想保住什么

- 自己和家人的性命；
- 商会信用、船粮网络和伙伴；
- 资产与原始账册；
- 救灾、借粮与买田三者的真实边界；
- 不被任何一方写成唯一奸商、唯一同谋或“自愿捐尽”的工具。

### 最害怕什么

- 官府需要他时叫义商，追责时叫奸商；
- 赈粮被写成买田，借粮被写成捐献；
- 自己救过的人最终成为指控自己的人；
- 账册无论落到谁手里，都只留下对那一方有利的几页；
- 自己的一切财富只是权力暂时寄存在他名下的东西。

### 与另外两人的不可调和冲突

- 对胡宗宪：总督把灾时征用看作公共义务，沈把无边界征用看作未来灭口的开始；
- 对郑泌昌：商会需要省府签收，省府却掌握交易性质和田契登记，既能保护也能重写商会行为。

### 七章变化

| 章节 | 沈一石的变化 |
|---|---|
| N1 | 发现清单重要却不足以自保；船真的救了人，官府仍会争谁下令、谁有功、谁付损失 |
| N2 | 看见自己的行为如何被奏稿改成另一种性质；是否交出原始船单成为第一次政治表态 |
| N3 | 从资源提供者变成决定百姓能否活过三日的人；每开一仓都同时改变粮价、债务和官府依赖 |
| N4 | 商路、异地往来和银票都能被解释成通倭；他必须公开部分商业秘密救人，或保网络而让别人赴死 |
| N5 | 粮船到埠，他第一次能正面规定“这批粮为何而来”；但任何用途都将损伤另一条生路 |
| N6 | 身体、资产和账册同时被争夺；不再相信完整保存一切可能，必须决定哪些材料、哪些人和哪一段真相优先活到 N7 |
| N7 | 仍以本人作最后一次决定：公开作证、秘密作证、以账册换家人、以沉默换生路，或让全部可核事实进入京师 |

### 最终可能得到与失去

他可能让灾民活下来、保住家人和部分商会信用，也可能失去全部资产、自由、名誉甚至生命。最终不能只按财富多少评判，而要看他用资源服务了谁、是否趁灾夺田、是否让账册成为公共事实，以及最后是否仍保有对自己命运的决定权。

# 四、三席关系的四条长期因果链

## 1. 军令—印信—实物链

胡宗宪提出方向，郑泌昌决定是否撤旧令、派差役、开放县道，沈一石再决定船粮是否按该路线投入。任何一环拒绝或拖延，都会在下一席现场表现为：没有回执、没有领路人、船停在埠头、军队等令或粮仓不开门。

## 2. 救急—登记—追责链

沈一石先动船粮，会让胡宗宪获得救灾空间；郑泌昌随后以省府登记决定这批资源究竟是什么。登记若被改写，沈会在后章公开原始清单；原始清单又会逼胡宗宪决定是否领衔保护商会或承认强征。

## 3. 证据—保护—采用链

清流 NPC 能保见证与材料，却需要胡宗宪提供保护、郑泌昌开放档案、沈一石提供原始账册。任何真人只提供“有利的一半”，都会让清流改变立场：从合作核验转为拒签、分别封存或公开保管风险。

## 4. 财政—地方—宫廷链

内阁财政以军饷和期限逼迫胡、郑；司礼监织造以宫廷名义控制材料与粮船；沈一石实际支付两条权力链的成本。三名真人任何一人把责任完全向上或向下切割，另一条渠道就会主动进入，形成更危险的第二版本。

# 五、三名强 NPC／AI 机构的七章行动合同

## 1. 清流法司

| 项目 | 内容 |
|---|---|
| 长期目标 | 让真实事实取得可采用的程序效力，同时阻止先造假案、后补证据 |
| 恐惧 | 真实只剩传闻；救急名义成为毁证理由；自己因过早定性让整案被推翻 |
| 筹码 | 证人保护、拒签、分别封存、案卷索引、核验、暂缓行刑、重审程序 |
| 底线 | 不把推断写成事实；不允许相反文书被无痕合并；不允许证人无记录失踪 |
| 主动行为 | 当三席想用统一口径越过矛盾时，清流会拒签、列出缺项、保护较弱证人，甚至改变材料去向 |

## 2. 司礼监织造

| 项目 | 内容 |
|---|---|
| 长期目标 | 保护宫廷名义，控制材料和物资进入内廷的方式，维持织造任务 |
| 恐惧 | 河道、粮船和账册牵出内廷人员；封簿被认定为灭证；外廷先定义宫廷责任 |
| 筹码 | 织造局名义、宫廷通行、监管簿、密奏、内廷使者、粮船灯号与收件渠道 |
| 底线 | 不许无页目无签收带走簿册；不许任何人冒称皇帝已有裁决；不让织造人员独自顶罪 |
| 主动行为 | 会在不同章分别开路、封簿、抢先收件、保护李玄、争夺账箱；局势不利时也会突然切割地方伙伴 |

## 3. 内阁财政

| 项目 | 内容 |
|---|---|
| 长期目标 | 维持国库、军饷、改桑期限和中央对地方叙述的控制 |
| 恐惧 | 承认期限错误引发全国仿效；地方把所有暴烈执行全部推给中央；军饷断裂 |
| 筹码 | 财政期限、军饷、中央收件、回批、政治保护、冻结资产和责任层级 |
| 底线 | 不接受无核数、无替代银源、无具名责任的求缓；不替皇帝预先表态 |
| 主动行为 | 会把地方每一次求援转成“谁补缺、谁签名”；在 N6 主动要求现金和资产，在 N7 决定接收哪一套事实包 |

三强 NPC 不组成固定反派集团：

- 清流要核验；
- 织造要控制；
- 财政要收束。

三者在多数关键场景中会互相冲突，迫使真人不能只选择“站正义一边”。

# 八、单人和三人模式共用原则

## 三人模式

- 三名玩家只读取自己的私人现场、可见事实和后果反馈；
- 同一公共事件可以在三处发生不同的个人压力，不要求所有人共享旁白；
- 玩家行动必须通过真实载体进入别人现场：急差、军令、船单、粮袋、证人、封条、田契、流言或 NPC 站队；
- 每章至少一次明确显示“因为另一名真人的行动，你眼前的人、资源、证据或危险发生了变化”。

## 单人模式

- 玩家选择任一真人席位，其余两席依照同一角色合同由 AI 执行；
- AI 只能使用该席已知与实际收到的材料，不读取玩家私密事实；
- AI 不为了帮助玩家自动合作，会谈判、拖延、拒绝、交换或自保；
- 世界因果、章节结果与 NPC 行为不因单人模式简化。
